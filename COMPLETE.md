**OR manually:**
```powershell

```

### 2. Configure (2 minutes)
Edit `.env` file with your settings (optional for testing - defaults work!)

### 3. Run (1 minute)
```powershell
npm start
```

### 4. Test (5 minutes)

**Option A: With Claude Desktop**
1. Add to `claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "ai-workflow-orchestrator": {
      "command": "node",
      "args": ["d:\\cardano_hackathon\\Cardano AI Agent\\dist\\index.js"]
    }
  }
}
```

2. Restart Claude Desktop
3. Use the orchestrator tools in conversation!

**Option B: Standalone Testing**
Run the orchestrator and connect with any MCP client.
